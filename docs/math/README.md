## 学年別ページ

- **[第1学年](grade-1.md)**：数の構成、加法と減法、ものの形、時刻
- **[第2学年](grade-2.md)**：4位数、筆算、乗法九九、長さとかさ
- **[第3学年](grade-3.md)**：除法、小数、分数、円と球、棒グラフ
- **[第4学年](grade-4.md)**：億と兆、概数、除法の筆算、面積、角、折れ線グラフ
- **[第5学年](grade-5.md)**：小数の乗除、異分母分数、合同、体積、割合、速さ
- **[第6学年](grade-6.md)**：分数の乗除、文字式、対称、比例と反比例、代表値

## 領域

- **A 数と計算**：全学年
- **B 図形**：全学年
- **C 測定**：第1学年から第3学年
- **C 変化と関係**：第4学年から第6学年
- **D データの活用**：全学年
- **数学的活動**：全学年
