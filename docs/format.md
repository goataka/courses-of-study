## ファイル構成

- **`docs/<段階>/README.md`**：段階の教科一覧。ID を持たない
  - 段階：`elementary` は小学校、`lower-secondary` は中学校
- **`docs/<段階>/<教科ID>/README.md`**：教科の目標と、学年別ページの一覧
- **`docs/<段階>/<教科ID>/grade-<学年>.md`**：学年の目標、内容、内容の取扱い
  - 補足：国語は2学年のまとまりで、`grade-1-2.md` のように書く
- **`docs/lower-secondary/social-studies/<分野>.md`**：中学校社会の分野ごとの目標、内容、内容の取扱い
  - 分野：`geography` は地理的分野、`history` は歴史的分野、`civics` は公民的分野
- **`docs/lower-secondary/science/field-<分野>.md`**：中学校理科の第1分野と第2分野
- **`docs/<段階>/<教科ID>/english.md`**：外国語の英語の目標、内容、指導計画の作成と内容の取扱い
- **`docs/<段階>/<教科ID>/planning.md`**：指導計画の作成と内容の取扱い
- **`docs/reference/<資料>/`**：学習指導要領以外の参考資料
  - 音訓：`docs/reference/onkun/`。書き方は[音訓の割り振り](reference/onkun/README.md#書き方)
- **`docs/elementary/japanese/kanji.md`**：小学校の学年別漢字配当表
  - 補足：中学校の学習指導要領には漢字配当表がない
- **`docs/<段階>/<教科ID>/commentary/`**：学習指導要領解説の転記
  - 書き方：[解説の転記](#解説の転記)
- **`docs/<段階>/<教科ID>/assessment/`**：評価規準の例の転記
  - 書き方：[評価規準の転記](#評価規準の転記)
- **教科ID**：`japanese`、`social-studies`、`math`、`science`、`foreign-language`

## ページの冒頭

- **形**：見出し1の下に、`- **項目名**：値` の箇条書きを置く
- **ID**：ページのID
- **コード**：ページに当たる学習指導要領コード
- **出典**：本文の文書名と、章と節
- **上位ページ**：一つ上のページ
- **前の学年**、**次の学年**：学年別ページだけが持つ

## 見出し

- **見出し2**：`目標`、`内容`、`内容の取扱い` などの大きなまとまり
- **見出し3**：領域
  - 例：`A 数と計算`、`知識及び技能`
- **見出し4**：内容の番号と見出し
  - 例：`A(4) 除法`
  - 見出しの語句：本文の語句から取る
- **見出しの下**：領域と内容は、ID とコードの行を持つ

## 項目の行

- **番号付きの項目**：`- **[番号](コードのURL)**：本文に沿って書き直した文`
  - 例：`- **[ア(イ)](https://w3id.org/jp-cos/8250233141200000)**：除法が用いられる場面を式に表し、式を読み取る`
- **文が複数ある項目**：番号の行の下に、文を1つずつ箇条書きにする
- **下位の項目**：字下げして、番号付きの項目として並べる
- **太字**：本文の重要語
  - 補足：番号の太字とは別に、文の中の太字は重要語を表す
- **文末**：常体とし、句点は付けない
- **番号のない文**：教科の目標の前文などは `- **全体**：` の形で書く
- **見出しを持つ番号**：本文で番号の後に見出しがある項目は、見出しを番号の後ろに続ける
  - 例：`**[ア 音声](コードのURL)**`
- **番号のない語の並び**：`- **一覧**：` の行に、`、` で区切って並べる
  - 例：言語の使用場面の例、言語の働きの例
- **記号**：本文の `{A∥B}` は、`{A、B}` と書く
  - 意味：括弧内のいずれかを用いる書き方

## 資質・能力の柱

- **形**：事項を柱ごとにまとめ、柱の名前を太字の行にする
- **柱**
  - 知識及び技能
  - 思考力、判断力、表現力等
  - 学びに向かう力、人間性等
- **目標**：番号の後ろに柱の名前を付ける
  - 例：`(1) 知識及び技能`

## 内容の取扱い

- **形**：番号付きの項目として並べる
- **対象**：`- **対象**：` の行に、その取扱いが対象とする内容の番号を書く
  - 例：`A(2)、A(3)`
  - 補足：親と同じ対象のときは省く
- **内容の側**：内容の見出しの下に `- **内容の取扱い**：` の行を置き、該当する取扱いの番号へリンクする

## 用語と人物の一覧

- **形**：`- **一覧**：` の行に、`、` で区切って並べる
- **リンク**：各語は、その語の学習指導要領コードへのリンクにする
- **読み**：本文に振り仮名がある語は、読みを `《》` で示す
  - 例：`聖武《しょうむ》天皇`
  - 位置：振り仮名が付く漢字の直後に置く

## 漢字配当表

- **総字数**：冒頭の `- **総字数**：` の行
- **学年**：見出し2の `第N学年`
- **字数**、**累計**：学年ごとの字数と、第1学年からの累計
- **漢字**：`- **漢字**` の下に、別表の掲載順に20字ずつ並べる
- **載せないもの**：読みや画数
  - 理由：学習指導要領の別表にないため
- **ある学年までの漢字**：その学年以下の漢字をつなぐ

## IDの決まり

- **形**：ページID の後ろに、本文の番号を `-` でつなぐ
- **ページID**：`<教科ID>-g<学年>`
  - 例：`math-g3`、`japanese-g12`、`jh-japanese-g1`
- **分野別ページのID**：`jh-<教科ID>-<分野>`
  - 例：`jh-social-studies-geography`、`jh-science-field1`
- **言語別ページのID**：`<教科ID>-<言語>`
  - 例：`foreign-language-english`、`jh-foreign-language-english`
- **段階**：中学校の ID は、先頭に `jh-` を付ける
  - 例：`jh-math-g1-A-1` は中学校 数学 第1学年 A(1)
  - 小学校：先頭に何も付けない
- **番号の表し方**
  - 領域：`A` から `D` をそのまま使う
  - かっこ付きの数字：数字だけにする
  - 片仮名：ローマ字にする
  - 対応：ア `a`、イ `i`、ウ `u`、エ `e`、オ `o`、カ `ka`、キ `ki`、ク `ku`、ケ `ke`、コ `ko`、サ `sa`、シ `shi`
  - 丸数字：数字だけにする
- **例**
  - `math-g3-A-4`：算数 第3学年 A(4)
  - `math-g3-A-4-a-a`：算数 第3学年 A(4)ア(ア)
  - `science-g3-A-1-i`：理科 第3学年 A(1)イ
  - `social-studies-g6-2-a-shi`：社会 第6学年 (2)ア(シ)
- **国語**
  - `K`：〔知識及び技能〕
  - 例：`japanese-g12-K-1-e` は (1)エ、`japanese-g12-A-2-a` は A(2)ア
- **書く場所**：ページ、領域、内容の ID だけを書く
  - 事項のID：見出しの ID と、項目の番号から上の決まりで求める
- **安定性**：ID は本文の番号から決まるため、文を直しても変わらない

## 原文の確認

- **文**：本文に沿って書き直した文であり、原文そのものではない
- **原文**：各番号のリンク先 `https://w3id.org/jp-cos/<コード>` で確認できる
- **コードの出典**：[学習指導要領コード](https://www.mext.go.jp/a_menu/other/data_00002.htm)
  - 発行：文部科学省
- **コードの参照元**：[学習指導要領LOD](https://jp-cos.github.io/)
  - 利用条件：クリエイティブ・コモンズ 表示 4.0
- **本文の出典**
  - 小学校：[小学校学習指導要領 平成29年告示](https://www.mext.go.jp/content/1413522_001.pdf)
  - 中学校：[中学校学習指導要領 平成29年告示](https://www.mext.go.jp/content/1413522_002.pdf)

## 解説の転記

- **対象**：各教科の学習指導要領解説の本文。まえがき、目次、付録は除く
  - 外国語：英語に関わる部分だけ。小学校の外国語活動は除く
- **出典**：各教科の `commentary/README.md` と各ページの冒頭に、題名、作成者、PDF の URL を書く
  - 表示：「を加工して作成」と添える
- **ファイル**：章、節、学年、領域、単元の順に分け、番号でつなぐ
  - 例：`03-01-02.md` は第3章 第1節 の2番目のまとまり
  - 目次：`commentary/README.md`
  - 大きさ：1ページ300行以内に収まるよう、長い節は単元や項目で分ける
- **見出し**：解説の見出しをそのまま使う
  - 補足：単元の見出しがない教科は、解説に引いた学習指導要領の項目から単元の見出しを作る
- **ページの冒頭**：出典、元の PDF のページ、上位ページ、前と次のページ
- **文言**：原文のまま。読点の「，」、全角のかっこ、全角の数字も変えない
- **整えた点**
  - 除いたもの：ページ番号、柱、余白の見出しのつまみ
  - 改行：段落の途中の改行をつなぐ
  - 学習指導要領の引用の枠：引用 `>` にする
  - 表：Markdown の表にする。複雑な表は読める範囲で行と列を保つ
  - ルビ：`漢字《よみ》` と書く
  - 分数：`分子/分母` と書く
  - (ア) などの記号の字形：`(ア)` と書く
  - 図と写真：載せず、「（図は省略）」と書く
- **読み取り**：PDF の文字を機械的に取り出したため、字の抜けや順序の乱れが残る場合がある
  - 確認：疑わしい箇所は、冒頭の PDF のページで原文を確かめる

## 評価規準の転記

- **元の資料**：国立教育政策研究所「『指導と評価の一体化』のための学習評価に関する参考資料」令和2年3月
- **対象**：巻末資料の「内容のまとまりごとの評価規準（例）」
  - 算数：「具体的な内容のまとまりごとの評価規準（例）」も載せる
  - 中学校理科：「中項目ごとの評価規準（例）」も載せる
- **ファイル**：学年ごと、または分野ごとに1ページ
  - 例：`grade-3.md` は第3学年、`detailed-grade-3.md` は第3学年の具体的な内容のまとまり
  - 分野：中学校理科は `field-1.md` と `field-2.md`、中学校社会は `geography.md`、`history.md`、`civics.md`
  - 目次：`assessment/README.md`
- **ページの冒頭**：出典、元の PDF のページ、上位ページ
- **見出し**：学年の目標と趣旨、領域、内容のまとまりの見出しをそのまま使う
- **評価規準の表**：「知識・技能」「思考・判断・表現」「主体的に学習に取り組む態度」の3列の表は、観点ごとの箇条書きにする
  - 項目：表の中の「・」で始まる文を1項目とする
  - ほかの表：Markdown の表にする
- **文言**：原文のまま。読点の「，」、全角の数字も変えない
- **整えた点**
  - 分数：`分子/分母` と書く
  - 指数：`x²` のように上付きの数字で書く
  - 除いたもの：ページ番号、余白の見出しのつまみ
- **読み取り**：PDF の文字を機械的に取り出したため、字の抜けや順序の乱れが残る場合がある
  - 確認：疑わしい箇所は、冒頭の PDF のページで原文を確かめる

## アプリからの利用

- **入口**：[README](../README.md) の教科一覧から、教科と学年のページをたどる
- **読み取り**：この形式は決まった書き方のため、一般的な Markdown のパーサーで読める
  - 階層：見出しと箇条書きの字下げ
  - 番号とコード：`**[番号](https://w3id.org/jp-cos/<コード>)**`
  - 重要語：文の中の太字
  - 対象：`**対象**` の行
- **検査**：`pnpm run check` が、行数、リンク、コードの形、漢字の字数を確かめる
