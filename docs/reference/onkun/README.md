## 位置づけ

- **種類**：学習指導要領の本文ではなく、文部科学省が作成した参考資料
- **性格**：各学校段階で指導する目安であり、学校は教科書教材などとの関連を考えて弾力的に扱える
- **実施**：小学校は令和2年度、中学校は令和3年度から
- **関係**：漢字の右の学年は、[学年別漢字配当表](../../elementary/japanese/kanji.md)の配当学年

## 書き方

- **分け方**：音訓を、割り振られた段階のページに載せる
  - 例：「悪」のアクとわるいは小学校 第3学年、オは高等学校のページ
  - 同じ漢字：段階ごとに別のページに出る
- **小学校の表**：列は漢字、音訓
  - 学年：ページで分かるため列を持たない
  - 空欄：媛、岐、滋、阪は小学校に割り振られた音訓がない。都道府県名の読みは付表2にある
- **中学校、高等学校の表**：列は漢字、配当学年、音訓
  - 配当学年：学年別漢字配当表の学年。配当学年がない漢字は空欄
- **音訓**：音は片仮名、訓は平仮名。原本の順に `、` で区切る
- **(特)**：原本で1字下げの音訓。特別なもの、または用法のごく狭いもの
- **(改)**：原本で下線が付いた項目。平成29年3月に割り振りなどを変更したもの
  - 配当学年の後ろ：配当学年を変更した漢字。中学校、高等学校の表にだけ付く
  - 音訓の後ろ：割り振りを変更した音訓
- **付表**：語、読み、段階の表。別の書き方は `、` で並べる

## 読み取りの注意

- **方法**：原本の PDF から文字と位置を読み取り、段階の欄の ○ と下線を位置から判定した
- **照合**：漢字の配当学年は、学年別漢字配当表と全て一致する
- **叱**：PDF のこの字には文字情報がなく、画像から読み取った
  - 字形：原本の表示どおり「叱」と書いた。常用漢字表の字形は「𠮟」
- **茨 いばら**：原本では他の1字下げより少し浅く右に寄っており、1字下げとは扱わなかった
- **付表1 しわす**：読みに付いた原本の注記は、そのまま残した
