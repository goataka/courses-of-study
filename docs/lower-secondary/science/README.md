## 教科の目標

- **全体**：自然の事物・現象に関わり、理科の見方・考え方を働かせ、見通しをもって観察、実験を行うことなどを通して、自然の事物・現象を科学的に探究するために必要な資質・能力を次のとおり育成することを目指す
- **[(1) 知識及び技能](https://w3id.org/jp-cos/8360100100000000)**：自然の事物・現象についての理解を深め、科学的に探究するために必要な観察、実験などに関する基本的な技能を身に付けるようにする
- **[(2) 思考力、判断力、表現力等](https://w3id.org/jp-cos/8360100200000000)**：観察、実験などを行い、科学的に探究する力を養う
- **[(3) 学びに向かう力、人間性等](https://w3id.org/jp-cos/8360100300000000)**：自然の事物・現象に進んで関わり、科学的に探究しようとする態度を養う
