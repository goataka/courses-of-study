## 教科の目標

- **全体**：言葉による見方・考え方を働かせ、言語活動を通して、国語で正確に理解し適切に表現する資質・能力を次のとおり育成することを目指す
- **[(1) 知識及び技能](https://w3id.org/jp-cos/8310100100000000)**：社会生活に必要な国語について、その特質を理解し適切に使うことができるようにする
- **[(2) 思考力、判断力、表現力等](https://w3id.org/jp-cos/8310100200000000)**：社会生活における人との関わりの中で伝え合う力を高め、思考力や想像力を養う
- **[(3) 学びに向かう力、人間性等](https://w3id.org/jp-cos/8310100300000000)**：言葉がもつ価値を認識するとともに、言語感覚を豊かにし、我が国の言語文化に関わり、国語を尊重してその能力の向上を図る態度を養う
