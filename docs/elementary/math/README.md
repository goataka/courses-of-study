## 教科の目標

- **全体**：数学的な見方・考え方を働かせ、数学的活動を通して、数学的に考える資質と能力を育成する
- **[(1) 知識及び技能](https://w3id.org/jp-cos/8250100100000000)**
  - 数量や図形などについての基礎的、基本的な概念や性質を理解する
  - 日常の事象を数理的に処理する技能を身に付ける
- **[(2) 思考力、判断力、表現力等](https://w3id.org/jp-cos/8250100200000000)**
  - 日常の事象を数理的に捉え、見通しをもち筋道を立てて考察する力を養う
  - 基礎的、基本的な数量や図形の性質を見いだし、統合的、発展的に考察する力を養う
  - 数学的な表現を用いて、事象を簡潔、明瞭、的確に表したり、目的に応じて柔軟に表したりする力を養う
- **[(3) 学びに向かう力、人間性等](https://w3id.org/jp-cos/8250100300000000)**
  - 数学的活動の楽しさや数学のよさに気付き、学習を振り返ってよりよく問題解決しようとする態度を養う
  - 算数で学んだことを生活や学習に活用しようとする態度を養う

## 学年別ページ

- **[第1学年](grade-1.md)**

  - B 図形：身の回りにあるものの形
  - C 測定：身の回りのものの大きさ、時刻
  - D データの活用：数量の整理

  - 用語・記号
- **[第2学年](grade-2.md)**
  - A 数と計算：数の構成と表し方、加法及び減法、乗法
  - B 図形：図形
  - C 測定：量の単位と測定、時刻と時間
  - D データの活用：データの分析
  - 数学的活動
  - 用語・記号
- **[第3学年](grade-3.md)**
  - A 数と計算：整数の表し方、加法及び減法、乗法、除法、小数とその表し方、分数とその表し方、数量の関係を表す式、そろばんを用いた数の表し方と計算
  - B 図形：図形
  - C 測定：量の単位と測定、時刻と時間
  - D データの活用：データの分析
  - 数学的活動
  - 用語・記号
- **[第4学年](grade-4.md)**
  - A 数と計算：整数の表し方、概数、整数の除法、小数とその計算、分数とその加法及び減法、数量の関係を表す式、計算に関して成り立つ性質、そろばんを用いた数の表し方と計算
  - B 図形：平面図形、立体図形、ものの位置、平面図形の面積、角の大きさ
  - C 変化と関係：伴って変わる二つの数量、二つの数量の関係

  - 用語・記号
- **[第5学年](grade-5.md)**
  - A 数と計算：整数の性質及び整数の構成、整数及び小数の表し方、小数の乗法及び除法、分数、分数の加法及び減法、数量の関係を表す式
  - B 図形：平面図形、立体図形、平面図形の面積、立体図形の体積
  - C 変化と関係：伴って変わる二つの数量、異種の二つの量の割合として捉えられる数量、二つの数量の関係
  - D データの活用：データの収集とその分析、測定した結果を平均する方法
  - 数学的活動
  - 用語・記号
- **[第6学年](grade-6.md)**
  - A 数と計算：分数の乗法及び除法、数量の関係を表す式
  - B 図形：平面図形、身の回りにある形の概形やおよその面積など、平面図形の面積、立体図形の体積
  - C 変化と関係：伴って変わる二つの数量、二つの数量の関係
  - D データの活用：データの収集とその分析、起こり得る場合
  - 数学的活動
