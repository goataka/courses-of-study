## 教科の目標

- **全体**：言葉による見方・考え方を働かせ、言語活動を通して、国語で正確に理解し適切に表現する資質と能力を育成する
- **[(1) 知識及び技能](https://w3id.org/jp-cos/8210100100000000)**：日常生活に必要な国語について、その特質を理解し、適切に使うことができるようにする
- **[(2) 思考力、判断力、表現力等](https://w3id.org/jp-cos/8210100200000000)**：日常生活における人との関わりの中で**伝え合う力**を高め、思考力や想像力を養う
- **[(3) 学びに向かう力、人間性等](https://w3id.org/jp-cos/8210100300000000)**
  - 言葉がもつよさを認識し、言語感覚を養う
  - 国語の大切さを自覚し、国語を尊重してその能力の向上を図る態度を養う
