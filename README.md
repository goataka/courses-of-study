# courses-of-study

小学校の**学習指導要領**の内容を、学習コンテンツやアプリの基礎データとして整理する

## 概要

- **対象**：小学校の**国語**、**社会**、**算数**、**理科**
- **基準**：小学校学習指導要領 平成29年告示
- **実施**：令和2年度から全面実施
- **範囲**
  - 教科の目標
  - 各学年の目標、内容、内容の取扱い
  - 指導計画の作成と内容の取扱い
  - 学年別漢字配当表
- **形式**：Markdown の箇条書き
  - 補足：決まった書き方のため、アプリからも読み取れる
- **方針**：学習指導要領に書かれている内容だけを載せる

## 構成

- **docs**：教科ごとのページ
  - [記載形式](docs/format.md)：書き方と ID の決まり
- **tools**：Markdown を検査するツール
- **[Agent.md](Agent.md)**：エージェント向けの指示

## 使い方

- **閲覧**：[教科一覧](#教科一覧)から学年のページを開く
- **アプリ**：[記載形式](docs/format.md#アプリからの利用)に沿って Markdown を読み取る
- **編集**：`docs/` の Markdown を直接直す
- **検査**：`pnpm run check` で、行数、リンク、コードの形、漢字の字数を確かめる
- **準備**：Node.js と pnpm を用意し、`pnpm install` を実行する

## 注意

- **文言**：各項目は本文に沿って書き直した文であり、原文そのものではない
  - 整えた点：文末、読点、かっこ書き、長い文の区切り
- **原文**：各項目のコードから確認できる
  - 方法：[原文の確認](docs/format.md#原文の確認)
- **見出し**：単元の見出しは本文の語句から取ったもので、本文に見出しがあるのは理科だけ
- **載せないもの**：解説、教科書の内容、授業時数、漢字の読み
- **改訂**：次期学習指導要領の審議が進んでおり、告示後は内容が変わる
