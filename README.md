## 概要

- **対象**：小学校の**国語**、**算数**、**理科**、**社会**
- **基準**：小学校学習指導要領 平成29年告示
- **実施**：令和2年度から全面実施
- **範囲**：各教科の「第2 各学年の目標及び内容」のうち「2 内容」
- **形式**：本文の要約による箇条書き

## 読み方

- **項目番号**：本文の番号をそのまま使う
  - 例：算数 第3学年 A(4)ア(ア)
- **ア**：主に**知識及び技能**
- **イ**：主に**思考力、判断力、表現力等**
- **国語の例外**：ア、イ、ウは指導事項の順番を示す
- **括弧**：項目番号の括弧は本文の表記に合わせる

## 注意

- **要約**：各項目は本文の要約であり、原文の文言ではない
- **正確な文言**：出典の本文で確認する
- **項目名**：算数と社会の項目名は内容を表す要約であり、本文の見出しではない
- **未照合**：算数の分数表記は出典のテキスト抽出で欠落するため、本文と機械的に照合していない
  - 対象：第2学年 A(1)ア(カ)、第3学年 A(1)ア(イ) と A(5)、第5学年 A(2)ア(ア)
- **漢字の字数**：学年別漢字配当表の字数は二次資料で確認
- **対象外**：各学年の目標、内容の取扱い、指導計画の作成は一部のみ記載
- **改訂**：次期学習指導要領の審議が進行中であり、告示後は内容が変わる
- **ルール**：記述は [agent-rules](https://github.com/goataka/agent-rules) の[ドキュメントルール](https://github.com/goataka/agent-rules/blob/main/rules/documentation.md)に従う
