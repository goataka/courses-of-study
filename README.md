## 概要

- **対象**
  - 小学校：**国語**、**社会**、**算数**、**理科**、**外国語**
  - 中学校：**国語**、**社会**、**数学**、**理科**、**外国語**
  - 外国語：英語のみ
- **基準**：小学校学習指導要領、中学校学習指導要領 平成29年告示
- **実施**：小学校は令和2年度、中学校は令和3年度から全面実施
- **範囲**
  - 教科の目標
  - 各学年の目標、内容、内容の取扱い
  - 指導計画の作成と内容の取扱い
  - 学年別漢字配当表
- **形式**：Markdown の箇条書き
  - 補足：決まった書き方のため、アプリからも読み取れる
- **方針**：学習指導要領に書かれている内容だけを載せる

## 構成

- **docs**：段階ごとのページ
  - **[小学校](docs/elementary/README.md)**：第1学年から第6学年
  - **[中学校](docs/lower-secondary/README.md)**：第1学年から第3学年
  - [記載形式](docs/format.md)：書き方と ID の決まり
- **tools**：Markdown を検査するツール
- **[Agent.md](Agent.md)**：エージェント向けの指示

## 使い方

- **閲覧**：[教科一覧](#教科一覧)から学年のページを開く
- **アプリ**：[記載形式](docs/format.md#アプリからの利用)に沿って Markdown を読み取る
- **編集**：`docs/` の Markdown を直接直す
- **検査**：`pnpm run check` で、行数、リンク、コードの形、漢字の字数を確かめる
- **準備**：Node.js と pnpm を用意し、`pnpm install` を実行する

## 注意

- **文言**：各項目は本文に沿って書き直した文であり、原文そのものではない
  - 整えた点：文末、読点、かっこ書き、長い文の区切り
- **原文**：各項目のコードから確認できる
  - 方法：[原文の確認](docs/format.md#原文の確認)
- **見出し**：小学校の単元の見出しは本文の語句から取ったもので、本文に見出しがあるのは理科だけ
- **追加した教科の文言**：小学校の外国語と中学校の各教科は、本文の読点、かっこ、文末を機械的に整えた文で、語句は本文のまま
  - 文末：「こと」「ものとする」を除き、「また、」で始まる文は「また、」を省く
  - 太字の重要語：付けていない
- **コード表の補正**：中学校の公民的分野と数学 第2学年の目標は、コード表の親子関係が本文と食い違うため、本文の順序で組み直した
- **載せないもの**：解説、教科書の内容、授業時数、漢字の読み
  - 外国語：英語以外の言語と、小学校第3学年及び第4学年の外国語活動
- **改訂**：次期学習指導要領の審議が進んでおり、告示後は内容が変わる
