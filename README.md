## 概要

- **対象**：小学校の**国語**、**社会**、**算数**、**理科**
- **基準**：小学校学習指導要領 平成29年告示
- **実施**：令和2年度から全面実施
- **範囲**
  - 教科の目標
  - 各学年の目標、内容、内容の取扱い
  - 指導計画の作成と内容の取扱い
  - 学年別漢字配当表
- **形式**：アプリ向けの JSON と、閲覧用の Markdown
- **方針**：学習指導要領に書かれている内容だけを載せる

## 構成

- **[data](data/catalog.json)**：正本のデータ
  - 入口：[data/catalog.json](data/catalog.json)
  - 形式：[データ形式](docs/data-format.md)
- **docs**：閲覧用のページ
  - 教科ごとのページ：データから生成する
  - [データ形式](docs/data-format.md)：JSON の形と ID の決まり
- **tools**：データの検査と、ページの生成を行うツール
- **[Agent.md](Agent.md)**：エージェント向けの指示

## 使い方

- **閲覧**：[教科一覧](#教科一覧)から学年のページを開く
- **アプリ**：[data/catalog.json](data/catalog.json) から各ファイルをたどる
- **編集**：`data/` の JSON を直し、`pnpm run build` でページを作り直す
- **検査**：`pnpm run check` で、型、テスト、生成物のずれを確かめる
- **準備**：Node.js と pnpm を用意し、`pnpm install` を実行する

## 注意

- **文言**：各項目は本文に沿って書き直した文であり、原文そのものではない
  - 整えた点：文末、読点、かっこ書き、長い文の区切り
- **原文**：各項目のコードから確認できる
  - 方法：[原文の確認](docs/data-format.md#原文の確認)
- **見出し**：単元の見出しは本文の語句から取ったもので、本文に見出しがあるのは理科だけ
- **載せないもの**：解説、教科書の内容、授業時数、漢字の読み
- **改訂**：次期学習指導要領の審議が進んでおり、告示後は内容が変わる
